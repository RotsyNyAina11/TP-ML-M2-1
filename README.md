# TP Machine Learning M2-1

Projet de Data Science structuré en trois parties (Clustering, Régression, Classification), basé sur des datasets classiques du domaine. Le projet est destiné à mettre en pratique les différentes étapes d’un pipeline Machine Learning : traitement des données, exploration, modélisation, évaluation et interprétation.

## 🔁 Structure du projet

- `Partie_A_Clustering.ipynb`
- `Partie_B_Regression.ipynb`
- `Partie_C_Classification.ipynb`
- `datasets/`
  - `Mall_Customers.csv`
  - `diabetes.csv`
- `requirements.txt`

---

## 📦 Installation

### 1. Cloner le projet

```bash
git clone git@github.com:RotsyNyAina11/TP-ML-M2-1.git
cd TP-ML-M2-1/TP-ML-M2-1
```
### 2. Créer un environnement virtuel
```bash
python -m venv env
```

### 3. Activer l’environnement virtuel
### Sous Windows :
```bash
env\Scripts\activate
```

### Sous Linux/macOS :
```bash
source env/bin/activate
```

##  Installer les dépendances
```bash
pip install -r requirement.txt
```

## 🚀 Lancer les notebooks avec VS Code
### Ouvrir le projet dans VS Code :
```bash
code .
```

1. Installer l’extension Jupyter si ce n’est pas encore fait.
2. Ouvrir un des fichiers dans notebooks/clustering/ ou notebooks/regression/ ou notebooks/classification.
3. Sélectionner le kernel Python correspondant à l’environnement virtuel env.
4. Exécuter les cellules pas à pas.
